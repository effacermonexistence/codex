# OS-1 자체 수리 파이프라인

OS-1은 자기 소스를 고치고 자기를 재설치한다. 사람 몫은 브라우저 로그인 승인과 GitHub 머지 클릭뿐이다.

1. 대화에 수정 요청을 보내면 백엔드(Claude/Codex)가 OS-1 소스 체크아웃에서 쓰기 작업으로 실행된다. 같은 체크아웃의 쓰기는 하나의 리스로 직렬화된다.
2. 백엔드의 일은 소스를 고치고 `swift build`와 자체검사를 초록으로 만드는 것까지다. 버전을 올리거나 스테이징을 직접 하지 않는다.
3. 작업이 소스 변경으로 끝나면 OS-1 런타임이 직접 마무리한다(`completeOS1SelfRepair`):
   - 설치본보다 큰 빌드 번호로 올리고 `os1RuntimeVersionString`을 번들과 맞춘다.
   - 서명된 유니버설 릴리스를 빌드하고 릴리스 자체검사 3종을 돌린다.
   - 스테이징 인텐트를 남긴다.
   - 변경분에서 자격증명 패턴을 스캔한다. 걸리면 커밋도 스테이징도 하지 않는다.
   - 현재 브랜치(main이면 전용 브랜치)에 커밋하고 푸시한다.
   - 한 일을 답변 끝에 기록한다. 스테이징이 실패하면 그 진단으로 작업이 실패 처리된다.
4. 실행 중인 앱은 작업이 하나도 없을 때 스테이징된 빌드를 검증 설치기로 설치하고, 대화와 대기열을 보존한 채 재시작한다.
5. 새 빌드로 살아난 앱이 요청한 대화에 설치 영수증을 한 번 남긴다. 실패한 설치는 이전 빌드로 자동 롤백된다.

수동 마무리: 백엔드가 소스만 고치고 끝난 트리는 `os1 self-repair complete --source <체크아웃>`으로 같은 파이프라인을 태울 수 있다.
