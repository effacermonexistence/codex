# Protected calibrated route evidence (conditional code, no shipped registration)

This is a host loader and source-consistency gate, not a model call, scientific
certificate, permission grant, or an installed live policy. No production
registration or real qualified dataset is supplied. Missing/invalid evidence
preserves the existing R0 route. Synthetic source-contract fixtures exercise the
positive conditional chain, but cannot authorize a real native transport.

## Fixed authority and reachable entrypoint

`loadHostCalibratedRouteRegistration({stateDir,now_ms})` reads **only**
`<stateDir>/calibrated-route-registration.json`. Undefined/absent/invalid roots
return null. The file is canonical, private current-UID0600, regular, nlink1,
NOFOLLOW/NONBLOCK, bounded and stable-read, with duplicate/unsafe keys rejected.
It names exact manifest/review hashes, explicit data mode, issue/expiry and code
hashes. A raw JSON copy cannot replace its reader-minted WeakMap registration.
The plugin can load this fixed entry independently of P9 mode. It must accept
only `loaded_qualified_evidence`; it must reject `loaded_synthetic_fixture_evidence`.
No model/task/plugin-JSON boolean or arbitrary evidence path issues a capability.

Registration is host-approved authority over exactly the named review bytes,
not self-authentication by a manifest or source hash. A malicious or mistaken
same-UID authorized writer is not cryptographically excluded. External source
originality, rights and scientific assumptions depend on the independently
reviewed originals and authoritative host registration; hashes do not prove them.

Promotion/registration changes require an explicit owner restart/reload. There
is no automatic hot-loading claim. Existing capabilities detect revocation but
never silently requalify changed proof bytes.

## Closed immutable proof inventory

`<stateDir>/calibrated-route-evidence/<manifestSHA>/` contains exactly:

- `manifest.json`
- `p7-input.json` (the original, complete P7 assess input)
- `p7-fit.json` (exact recomputed artifact)
- `p8-evidence.json` (fresh original heldout evidence, source-backed execution windows and original source captures)
- `resource-partitions.json` (independent strict ten-component source observations)
- `host-records.json` (protected source-bound current pre-outcome records; empty is allowed)
- `promotion-review.json` (separately host-pinned independent review)

The manifest payload binds exact current cohort/native harnesses, reference,
feature recipe, scope and regime, plus explicit projection policy. The review
binds that payload and the original P7, P8, resource and host-record file hashes.
The manifest does not embed its own hash in the review, avoiding circular hash
claims. Root registration independently pins both manifest and review SHA.

P7 input and fit are fully recomputed, with policy pass required; original
train/calibration identities/phase locks remain intact. P8 is joined against
original exact attempts/configs/locks/grades, paired to an appropriate P7 pair,
with source-bound pre-outcome projection/stratum and execution **after** calibration freeze, independent grade after
final lock, complete resources, zero accepted_B/task failures and disjoint
train/calibration/heldout request/source/template/project fingerprints. A
heldout-only source card's `calibration_sample_insufficient` precheck is resolved
by the independently recomputed P7 calibration, not by relabelling heldout rows.
The complete cost-TRAIN history proof is verified before heldout processing. A
metadata-only firewall compares every cost-TRAIN and P7 TRAIN/CAL request, source,
template and project fingerprint against **all** P8 cards before any heldout grade
join. Quality-TRAIN and cost-TRAIN may intentionally reuse an original observation;
neither may overlap calibration or heldout data.
All other P8 blockers reject. EACH exact projected P7 stratum must have its own
frozen heldout minimum; one pair or another feature bucket cannot qualify all cells. Review source bytes, not just approval booleans,
are required. Timestamp assertions remain source-consistency evidence, not
privileged observation of hidden historical state.

## Statistical and resource meaning

The returned `policy` and `fit` are exact P7 originals. There are no new default
quality thresholds, empirical families, or guessed native capacities. Projection
policy explicitly fixes point=`training_mle_v1` and
lower=`minimum_training_point_and_calibration_bound_v1`; the predictor must also
check task-success/floor/holdout and current R0, not equate match with success.

P7's scalar one-native-attempt total cannot be split into ten guessed values.
Every partition observation independently supplies all ten disjoint components
and original source bytes, bound to exact case/arm/outcome/config. Its sum must
match that case's already verified supported P7 total. Single-attempt partition sums are checked only as original P7 evidence; they
do not establish future fallback cost. A separate frozen `whole_route_policy`
and complete source-bound TRAIN route episodes are mandatory. Every episode
binds its pre-outcome feature/regime/harness stratum, normalized primary and
zero/one actual reference fallback after a source-bound registered-checker
rejection, ordered closed original history and explicit disjoint host overheads.
Unknown usage, omitted rejection fallback or missing tuple coverage rejects.
Distinct logical outcome IDs do not establish independent native observations.
Across all cost episodes/attempts, provider/account/transport namespaced repeated
session+turn identity rejects as observation reuse. Repeated execution identity
with distinct claimed turns is unsupported/ambiguous: the execution ID may name
an adapter envelope, not a provider execution. A shared record SHA identifies an
artifact, possibly an entire session; it does not prove turn duplication. This
initial scope conservatively rejects shared-artifact cases until a separately
verified per-turn witness is available. Same session with independent turn,
execution and artifact identities remains supported. These checks are source
consistency gates, not authentication of a provider's hidden physical execution.
Only those complete TRAIN-history episode means enter normalized cost rows,
with original resource-file hash and episode count; P8 is never used to fit or
tune costs. Retry-reserve estimates include observed fallback attempt usage.
These empirical means are estimates, not upper confidence bounds. Ref/candidate/current-R0 costs require their own
matching qualified cells; no phantom third cost or unknown-to-zero conversion.
These are observed-history token estimates, not quota/cash or a future-cost
closure guarantee. Broader retry/graph scopes require their own evidence.

## Current host records and separation

A host record is `{record_sha256,captured_at_ms,prepared}` with exact prepared
selector/current-binding/feature/original-R0/boundary objects. Capture time is
included in its source hash, equals selector-input capture time and cannot be
future or after the independent review. Pre-outcome selector fields calibration,
forecasts and host_evidence must be null. The predictor's protected default
preparer matches current task/node/request/source/baseline-plan/config/reference
and current bindings; it does not import records from task data or fill unknown
family/token/tool/capability observations. Snapshot identity and source-body hash
must retain their declared distinct meanings.

`readCalibratedRouteEvidence(capability,{now_ms})` accepts only the loader's
private brand. A full proof recomputation happens once at load. Each access
cheaply verifies fixed registration identity, all source/code file identities,
expiry, canonical directory custody and the closed artifact-root inventory.
Directory custody compares dev/inode/mode/UID, not root mtime/size: ordinary Core
SQLite/WAL/native-input writes in the same state directory do not revoke trust.
An artifact inventory change or changed source/code/registration file does.
No per-token full8MiB proof recomputation is performed. Source/code modules may
be root-owned or current-UID-owned, but never group/other-writable; private proof
files remain current-UID0600. This is not filesystem/crash atomicity or an SLO.

The returned immutable bundle retains data/proof modes and source-review limits.
`isCalibratedRouteEvidence` is identity only, not a fresh authorization check.
All result authority/certificate flags remain false. Runtime independently keeps
R0 admission, runnable fallback, exact original read-only task, fresh catalog,
atomic reservation, source/permission, verifier, cancellation and adoption gates.

## Fixture and dependency boundaries

The unbundled `calibrated-route-evidence.synthetic.mjs` writes private temporary
**synthetic** original P7/P8/partition/review packages and calls the real loader.
Three-config mode fits two independent original pairs and sources real synthetic
partition means: routed36 < currentR0floor76 < frontier106. The two nonreference
cost histories include one actual synthetic reference fallback among ten; the
underlying P7 single-attempt means remain26/66 and are not renamed as whole-route cost. Those numbers are test
premises, not OS1 performance or statistical thresholds. `prepareRecords` receives
a detached copy of fixture facts, never a writable alias into proof originals.

Runtime fixture-origin acceptance must separately require the private temporary
fake executor gate; production must reject synthetic capabilities. No public test
mode can mint production authority.

The sealed runtime dependency closure includes calibrated evidence/predictor,
offline-route-calibration, frozen-route-evidence, frozen-route-artifacts,
frozen-route-predictor, joint-route-selector, routing-outcome, rcc-runtime and
rcc-plugin. Registration pins all these producing/projecting/adopting modules.
Fixture helpers/tests/docs are not runtime resources. Root owns packaging/hash
updates. Source code without qualified real data does not close P7, P8, generic
DAG, full quality, quota savings or live product adoption.
