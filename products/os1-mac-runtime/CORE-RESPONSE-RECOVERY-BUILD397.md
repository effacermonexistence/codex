# Build 397: response ownership and bounded observer recovery

Source-level repair record. Installed end-to-end qualification, native overlap
and task-quality comparisons remain separate gates; this is not a product
completion or flagship-parity receipt.

## Retained observations

The installed 396 response-path question went through local planning and a
native Codex worker. Core saved its returned answer, but a subsequent observer
timeout left the UI displaying an unavailable connection instead. A late Stop
and completion occurred near each other; their exact causal ordering is not
inferred from display timestamps.

Two further unchanged development tasks were held before any native worker
started. One singleton planner annotation omitted the original's final LF; the
other paraphrased it and omitted detailed original constraints. Those raw outputs,
held statuses and zero-native-call records remain failures of 396. A successful
compiler replay does not relabel them as successful model execution.

## Repairs in the existing execution path

* The existing native `StatusCheckIn` recognizer supplies a narrow response-path
  intent to the same Core compiler. It must be an Auto request with no explicit
  provider, attachment, separate objective or execution request. Core emits its
  own bounded local response and local child; neither a hosted agent nor a
  local planner is needed. It does not certify external backends or earlier
  tasks. The duplicate JavaScript Korean phrase table is retired; external,
  tool, completion and installation questions retain their actual task route.
* The existing indivisible-agent original-instruction lock also applies during
  compact-v2 decoding. For one agent, a typed, bounded planner instruction is
  non-authoritative annotation: the host restores the original request bytes.
  Grade, scope, paths, references, dependencies and source binding still pass
  their independent checks. Deterministic instructions retain their separate
  exact-operation gate; multi-node decomposition is unchanged. Oversized
  originals are not truncated or copied beyond the existing node bound. No
  fallback planner, reference model or extra controller is introduced.
* After a positive acknowledgement of the immutable whole submitted request,
  an ambiguous status transport timeout/failure gets at most one same-owner,
  same-task bounded status reconciliation across the run. There is no second
  submit, replan, provider selection or new owner. Request SHA and monotonic
  revision checks remain mandatory. Authenticated refusals, custody, identity,
  schema and revision failures remain hard failures. The status wire does not
  contain source/policy hashes: source authority is the admitted whole request,
  not invented status fields. Late Stop sends at most one cancellation intent;
  an already-settled actual terminal result wins over an observer error.

## Verification and non-regression gates

Offline fixtures cover response-only intent versus external/action questions;
singleton original-byte preservation versus authority injection, deterministic
operation changes and real DAGs; and observer timeout versus authenticated
refusal, owner/hash/revision mismatch and cancellation. The old observer is
tested against a Core-saved result to reproduce the prior failure.

Release qualification additionally requires the installed UI to render the
local health result and one local child, two explicitly requested native Codex
workers to return their exact answers with overlapping native turn intervals,
and unchanged development tasks to reach their terminal result before grading.
All answer locks precede grading. Cached direct references retain their exact
source and any prior grading ambiguity. These inspected cases are post-dev
reproduction, not fresh held-out public proof or evidence of universal parity.

Sessions, queued requests, drafts, paging originals, raw failed outputs and
previous verified release artifacts must survive installation. ChatGPT relay,
OhMyBug restoration, API fallback, browser workarounds and unrelated connector
repair remain outside this change.
